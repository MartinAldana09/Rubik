Para vos

Cómo agregar tus videos, fotos y textos

No hace falta tocar el diseño

  1. Abrí el archivo js/content.js. Ahí vive un array llamado CUBES, con un bloque por cada cubo (3×3, 4×4, 5×5, Mirror, Pyraminx).
  2. Para editar un cubo existente, buscá su bloque (empieza con id: "3x3", id: "4x4", etc.) y cambiá titulo, subtitulo y descripcion de cada paso dentro de steps.
  3. Para el video de cada paso: si lo subiste a YouTube, poné el ID en video.id (lo que va después de watch?v= en la URL). Si preferís un archivo propio, cambiá tipo a "local" y la ruta en src, por ejemplo assets/video/4x4-paso1.mp4.
  4. Para las fotos: guardá tus imágenes dentro de assets/img/ y listalas en el array imagenes de cada paso.
  5. Para agregar un cubo nuevo: copiá un bloque completo de CUBES (desde su { hasta su }), pegalo antes del cierre de la lista, y cambiá id, nombre, dificultad, color, resumen y los steps. Aparece solo como una tarjeta nueva en el menú.
  6. Para la galería general, editá el array GALERIA al final del mismo archivo.
  7. Guardá el archivo y subí el cambio a GitHub (o volvé a arrastrar la carpeta a Netlify).
