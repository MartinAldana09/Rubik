Para vos

Cómo agregar tus videos, fotos y textos

No hace falta tocar el diseño

  1. Abrí el archivo js/content.js.
  2. Para cada paso, cambiá titulo, subtitulo y descripcion por tu propio texto.
  3. Para el video: si lo subiste a YouTube, poné el ID del video en video.id (lo que va después de watch?v= en la URL). Si preferís un archivo de video propio, cambiá tipo a "local" y poné la ruta en src, por ejemplo assets/video/paso1.mp4.
  4. Para las fotos: guardá tus imágenes dentro de assets/img/ y listalas en el array imagenes de cada paso, por ejemplo "assets/img/paso1-a.jpg".
  5. Para la galería general, editá el array GALERIA al final del mismo archivo.
  6. Guardá el archivo y volvé a subir la carpeta a Netlify (o hacé push si lo conectaste a un repo de GitHub).
